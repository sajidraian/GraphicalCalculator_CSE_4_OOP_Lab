# 🧮 Graphical Calculator - CSE 4 OOP Lab

A Java Swing-based Graphical Calculator developed as part of the **Object-Oriented Programming (OOP) Lab** coursework.

## 📌 Features

- Basic arithmetic operations
  - Addition (+)
  - Subtraction (-)
  - Multiplication (×)
  - Division (÷)
- User-friendly graphical interface
- Unit Converter
- Error handling for invalid inputs
- Object-Oriented design using Java classes

## 🛠️ Technologies Used

- Java
- Java Swing (GUI)
- Object-Oriented Programming (OOP)

## 🚀 How to Run

### Using Command Prompt

1. Clone the repository

```bash
git clone https://github.com/sajidraian/GraphicalCalculator_CSE_4_OOP_Lab.git
```

2. Navigate to the project folder

```bash
cd GraphicalCalculator_CSE_4_OOP_Lab
```

3. Compile the Java files

```bash
javac *.java
```

4. Run the project

```bash
java Main
```

### Using IntelliJ IDEA / Eclipse / VS Code

- Import the project.
- Open `Main.java`.
- Click **Run**.
